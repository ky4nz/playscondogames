WAJIB EXTRACT DULU — JANGAN dipakai langsung dari dalam ZIP
===========================================================

File yang kamu download adalah ZIP berisi FOLDER + BANYAK FILE TERPISAH.
Kalau tidak di-extract, isinya tidak bisa dipakai / tidak bisa di-upload ke GitHub.

Windows:
  1. Klik kanan playscondogames-source-....zip → Extract All...
  2. Pilih folder tujuan → Extract
  3. Masuk ke folder hasil: playscondogames/

Mac:
  1. Double-click file .zip
  2. Masuk ke folder hasil: playscondogames/

HP Android:
  1. Buka aplikasi Files / File Manager
  2. Tap file .zip → Extract

Setelah extract kamu dapat:
  playscondogames/
  ├── src/            (semua kode, terpisah per file)
  ├── public/         (gambar/video)
  ├── package.json, tsconfig.json, next.config.ts, ...
  ├── README.md, DEPLOY.md, .env.example, vercel.json
  └── README-OWNER.txt (file ini)

Upload ke GitHub: upload ISI folder playscondogames/ (bukan file .zip-nya).
